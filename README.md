# ОМ Студия — каталог керамогранита и плитки

## Правила проекта (обязательные)

1. **npm registry — только публичный.** Все зависимости устанавливаются с `https://registry.npmjs.org/`. Это зафиксировано в `.npmrc` в корне проекта. Не добавлять и не использовать сторонние зеркала (npm mirrors) в `package-lock.json` и `.npmrc`. Перед передачей архива проекта проверять:

   ```bash
   grep -R "npm.mirrors.msh.team" package-lock.json .npmrc 2>/dev/null
   ```

   Команда не должна возвращать ни одной строки.

2. **Портативность.** Проект должен разворачиваться на чистой macOS/Linux-машине: `npm install && npm run build && npm start` (после настройки `.env`, см. `.env.example`). Никаких путей и сервисов, специфичных для конкретной машины разработчика.

3. **Данные поставщиков — только на сервере.** Имена поставщиков, URL выгрузок и любые доступы не должны попадать во фронтенд-бандл и в публичные API-ответы. Все упоминания — только в `api/` (серверный код).

4. **Цены и остатки.** На сайте выводятся только розничные цены. Дилерские цены не показываем никогда. Количество остатков по складам не показываем — только статус («В наличии» / «Заканчивается» / «Под заказ»), точный метраж уточняет менеджер.

5. **Перед сдачей изменений** обязательно:

   ```bash
   npm install
   npm run check
   npm run build
   ```

## Стек

- Фронтенд: React 19 + TypeScript + Vite + Tailwind + shadcn/ui
- Бэкенд: Hono + tRPC 11 + Drizzle ORM + MySQL
- Импорты поставщиков: node-cron (каждый час), адаптеры в `api/importers/`

## Обновление проекта до новой версии (важно!)

1. Распаковывайте архив **рядом** со старой папкой, а не внутрь неё (иначе получится `app/app 2`).
2. **Скопируйте из старой папки в новую файл `.env`** — в нём `DATABASE_URL` и пароль админки. Без этого файла сайт откроется, но каталог будет пустым (признак: предупреждение `VITE_YM_ID is not defined` при запуске).
3. Остановите старый сервер, иначе порт будет занят: `lsof -ti:3000 | xargs kill -9`
4. В новой папке: `npm install` → `npm run dev`.
5. Если в новой версии появились новые скрипты `db/migrate-*.mts` — выполните их один раз: `npx tsx db/<имя файла>.mts` (`.env` подхватывается автоматически; если видите `Failed query` / `Access denied` — значит, `DATABASE_URL` не подгрузился: проверьте, что `.env` лежит в корне проекта и команда запущена из папки проекта, а не из родительской)
6. Не запускайте `npm install` в родительской папке без `package.json` — npm создаст там пустой мусорный `package-lock.json`.

## Команды

| Команда | Назначение |
|---|---|
| `npm run dev` | dev-сервер с HMR, http://localhost:3000 |
| `npm run build` | продакшн-сборка в `dist/` |
| `npm start` | запуск продакшн-сервера |
| `npm run check` | проверка типов TypeScript |
| `npm run db:push` | синхронизация схемы БД |
| `npx tsx db/import-cli.ts all` | ручной запуск импорта всех поставщиков |

## Настройки

- `src/lib/config.ts` — телефон, почта, адрес шоурума, часы работы, ссылки на мессенджеры (Telegram / WhatsApp / MAX).
- `.env` — `DATABASE_URL`, `ADMIN_PASSWORD` (вход в /admin), `VITE_YM_ID` (Яндекс Метрика).
